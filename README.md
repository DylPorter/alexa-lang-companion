# Sala (working name) — the living-room language companion

Amazon "Build, Ship, Shape" Developer Hackathon entry (`amazonappdev2026`), **Alexa+ track**. MIT licensed.

An Alexa+ companion MCP server that acts as a living-room friend: it remembers your daily
activities and past conversations, sustains everyday chat in your target language using that
personal context, and ends each session with grammar/vocabulary review lists generated from
what you actually discussed.

**Status: A1 (server core) in build.** Full spec: [SPEC.md](SPEC.md). Demo path: the rules'
sanctioned web-app simulation of the Alexa+ experience — no hardware required.

Prior-work note: clean-room build; the LLM-backend-swap pattern follows the author's own
in-window `firetv-factcheck` backend (same hackathon, same author, separate submission).
